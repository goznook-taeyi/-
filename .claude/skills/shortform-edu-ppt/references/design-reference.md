# 숏폼 교육 PPT 디자인 레퍼런스 분석

> 사용자가 제공한 레퍼런스 2장(포트폴리오형 "PROJECT GOAL" 슬라이드, "Interview/Persona" 슬라이드)을 분석한 문서.
> `shortform-edu-ppt` 스킬과 `scripts/build_pptx.py`의 기본 테마가 이 문서를 따른다.

## 0. 총평 — 어떤 디자인인가

토스·당근마켓 계열의 **한국형 프로덕트 디자인 언어**다. 핵심 문법은 다음 다섯 가지.

1. **단일 액센트**: 비비드 바이올렛 하나만 쓰고, 나머지는 전부 그 틴트(라벤더)와 무채색으로 통일
2. **큰 라운드 + 부드러운 깊이**: 모서리 반경 20~28px 카드, 진한 외곽선 대신 옅은 확산 그림자
3. **모서리에 겹쳐 띄우는 오브젝트**: 3D 글래스 아이콘·이모지를 카드 경계에 걸쳐 배치해 평면을 깨는 깊이감
4. **굵은 타이포 위계**: 얇은 장식체 없이 Bold/Medium 두 굵기와 크기 차이만으로 위계를 만듦
5. **여백이 레이아웃**: 요소를 채우지 않고 비운다. 섹션 사이 세로 여백이 본문 높이만큼 큼

교육 PPT 관점에서 이 문법은 **이중부호화(텍스트+시각)와 인지부하 관리에 유리**하다 — 슬라이드당 개념 1개, 카드당 메시지 1개 구조가 이미 내장돼 있다.

## 1. 컬러 토큰

| 토큰 | 값 | 용도 (레퍼런스에서의 쓰임) |
|---|---|---|
| `primary` | `#6C2BD9`~`#7C3AED` | Goal 밴드 배경, 배지, 카드 제목, 강조 단어, 진행바 |
| `primary-deep` | `#5B21B6` | 그라데이션 끝점, 진한 강조 |
| `lavender-100` | `#EDE9FE` | 해시태그 칩 배경, Needs 패널, 진행바 트랙 |
| `lavender-300` | `#C4B5FD` | 대형 워터마크 문자(A/B), 보조 장식 |
| `gradient-sky` | `#C7C2F5 → #9F8DF2` (대각선) | 상단 히어로 섹션 배경 (Interview 슬라이드) |
| `bg-canvas` | `#F5F4F7` (웜그레이) | 슬라이드 기본 배경 — 순백이 아님 |
| `card-gray` | `#E9E7EE` | 솔루션 카드 배경 (배경보다 한 톤 어두운 회색) |
| `card-white` | `#FFFFFF` | 퍼소나 카드 (그림자로 배경과 분리) |
| `glass-white` | `#FFFFFF @ 45~60% 투명` | 그라데이션 위 말풍선 카드 |
| `ink` | `#1A1A1E` | 제목 텍스트 (순검정 아님) |
| `ink-sub` | `#5C5C66` | 본문/설명 텍스트 |

**규칙**: 유채색은 바이올렛 계열 하나뿐. 빨강·파랑·초록을 섞지 않는다. 강조가 필요하면 색을 바꾸지 말고 `primary`로 통일한다.

## 2. 타이포그래피

| 역할 | 스타일 | 예시 |
|---|---|---|
| 아이브로(eyebrow) | 영문 대문자, 12~14pt, Bold, 자간 +5~10%, `primary` | `PROJECT GOAL` |
| 슬라이드 제목 | 28~40pt, Bold(700), `ink`, 한 줄 | 밀도의 최종 목표를 설정했어요 |
| 리드 문단 | 12~14pt, Regular, `ink-sub`, 행간 1.6, 2줄 이하 | 데스크 리서치를 통해… |
| 카드 제목 | 16~20pt, Bold, `primary` | 맞춤형 뉴스레터 |
| 카드 본문 | 11~13pt, Regular, `ink-sub`, 행간 1.55 | 유저의 관심사에 맞는… |
| 배지/칩 | 10~12pt, SemiBold, 흰색(배지) 또는 `primary`(칩) | Solution 1, #쾌활한 |
| 강조 단어 | 본문과 같은 크기, Bold + `primary` 색만 변경 | 트렌드 지향형 나금손 |

- 서체: **Pretendard** (없으면 맑은 고딕/Noto Sans KR 폴백). 세리프·손글씨 계열 금지.
- 제목·아이브로·본문 3단 위계를 항상 유지. 위계는 색·크기·굵기로 만들고 밑줄·기울임은 쓰지 않는다.
- 영어 라벨(eyebrow, 배지)과 한글 본문을 섞는 것이 이 스타일의 시그니처.

## 3. 박스(카드) 디자인

### 3-1. 기본 카드 (솔루션 카드)
- 배경보다 **한 톤 어두운 회색**(`card-gray`) 채움, 외곽선 없음
- 모서리 반경 24px 내외 (슬라이드 폭의 ~2%)
- 내부 패딩 넉넉히(카드 폭의 10% 이상), 구성: 제목 → 얇은 디바이더(1px, #D9D6E0) → 본문
- **배지가 카드 상단 변에 걸침**: `primary` 채움의 작은 라운드 사각형(반경 8px), 흰 글씨, 카드 위 테두리에 반쯤 겹치게 배치

### 3-2. 글래스 말풍선 (Pain point 카드)
- 그라데이션 배경 위, 반투명 흰색(45~60%) + 큰 반경(모서리 하나는 거의 pill)
- 3장을 **좌 → 우 → 중앙 지그재그**로 엇갈리게 배치해 리듬을 만듦 (그리드 정렬 금지)
- 카드 모서리 밖으로 **큰 이모지(64~80px)가 절반쯤 걸쳐** 떠 있음 — 감정 상태를 텍스트보다 먼저 전달

### 3-3. 흰색 정보 카드 (퍼소나 카드)
- 순백 채움 + 부드러운 확산 그림자(blur 30px, 투명도 8~12%, 아래 방향)
- 카드 밖 좌상단에 **초대형 워터마크 문자**(80pt+, `lavender-300`) + 라벨
- 내부: 아바타(원형/이모지) + 2줄 소개 + `primary` Bold 이름 → 점선 디바이더 → 데이터 행

### 3-4. 강조 밴드 (Goal 밴드)
- 슬라이드 폭 전체를 쓰는 `primary` 채움의 큰 라운드 박스
- 흰 글씨 2줄, 중앙 정렬, 위에 작은 라벨(Goal)
- 결론·요약·CTA 등 **슬라이드당 1회만** 사용. 캐릭터/오브젝트가 밴드 하단에 걸치면 더 좋음

## 4. 이모지·아이콘 운용

- **이모지는 장식이 아니라 정보**: 말풍선의 😕🤔처럼 내용의 감정/상태를 요약하는 자리에만 쓴다. 불릿 대용 이모지 남발 금지
- 크기는 본문의 4~6배로 **크게, 적게** (슬라이드당 1~3개)
- 카드 안이 아니라 **카드 경계에 걸치게** 배치해 깊이를 만든다
- 3D 글래스 아이콘(편지·폴더·사람)은 이모지의 상위호환 — 이미지 에셋이 필요하며, 없으면 큰 이모지로 대체해도 문법이 유지됨

## 5. 그라데이션

- 방향: 대각선(좌상 → 우하) 또는 세로, **라벤더 → 페리윙클**의 저채도 파스텔 (`#C7C2F5 → #9F8DF2`)
- 쓰는 곳: 섹션 히어로 배경, 진행바 채움(`#A78BFA → #7C3AED`)
- 쓰지 않는 곳: 텍스트, 카드 배경, 작은 요소. **한 슬라이드에 그라데이션 면은 1개**
- 그라데이션 위 텍스트는 흰색, 카드는 반투명 흰색으로 통일

## 6. 레이아웃 문법

- **캔버스**: 16:9(발표용, 기본) / 9:16(세로 영상용). 바깥 마진은 짧은 변의 8% 이상
- **섹션 인트로 패턴**: 작은 마크(로고/도형) → 굵은 제목 → 회색 설명 1~2줄, 모두 중앙 정렬
- **좌상단 아이브로 패턴**: 아이브로 → 제목 → 리드, 모두 좌정렬 (본문형 슬라이드)
- **N분할 카드 행**: 동일 폭 카드 2~3장 + 카드 사이 간격은 카드 폭의 12~15%
- **연결선**: 카드 하단 중앙에 `primary` 점(dot) → 가는 선(1.5px)으로 아래 결론 밴드에 수렴. 흐름(원인→결론)이 실제로 있을 때만 사용
- **지그재그**: 나열이 3개 이상이고 순서가 없으면 격자 대신 엇갈림 배치로 리듬
- 요소 수 상한: **슬라이드당 텍스트 블록 5개 이하** (제목+리드+카드3장 수준)

## 7. python-pptx 구현 가능성 (feasibility)

| 요소 | 가능성 | 구현 방법 |
|---|---|---|
| 컬러 토큰·웜그레이 배경 | ✅ 완전 | 슬라이드 배경 solid fill |
| 라운드 카드 + 배지 + 칩 | ✅ 완전 | `MSO_SHAPE.ROUNDED_RECTANGLE` + adjustment로 반경 제어 |
| 타이포 위계·강조색 Bold | ✅ 완전 | run 단위 폰트/색 지정 (Pretendard 미설치 시 맑은 고딕 폴백) |
| 그라데이션 배경/진행바 | ✅ 완전 | `fill.gradient()` + gradient_stops 색·각도 지정 |
| 진행바(트랙+채움+%) | ✅ 완전 | pill 사각형 2겹 + 우측 텍스트 |
| 점·선 연결선 | ✅ 완전 | `add_connector` + 타원 |
| 이모지(대형) | ✅ 대부분 | 텍스트 런으로 삽입. PowerPoint/키노트에서 컬러 렌더, LibreOffice 렌더는 흑백일 수 있음 |
| 반투명 글래스 카드 | 🟡 근사 | 투명도는 XML(`<a:alpha>`) 직접 주입으로 구현(스크립트에 내장). **배경 블러는 PPTX에 없음** → 저대비 그라데이션 위에선 블러 없이도 유사한 인상 |
| 부드러운 확산 그림자 | 🟡 근사 | shadow XML(`<a:effectLst>`) 주입. 기본값보다 연하고 크게 |
| 3D 글래스 아이콘·퍼리 캐릭터 | 🔴 에셋 필요 | 벡터로 재현 불가. PNG 에셋을 구해 `add_picture`로 삽입하거나 대형 이모지로 대체 |

**결론: 접근 가능.** 레이아웃·컬러·타이포·카드·배지·칩·그라데이션·진행바 등 문법의 90%는 python-pptx로 그대로 재현되고, 글래스 블러와 3D 오브젝트만 근사(반투명)·대체(이모지)·에셋(PNG)로 푼다.
